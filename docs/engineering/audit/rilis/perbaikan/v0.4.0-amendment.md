### Correction 1: "Version bump only" is inaccurate

`audit/rilis/v0.4.0.md` states "Version bump only: workspace `0.3.0` →
`0.4.0`". That phrase understates the release: tagging v0.4.0 also shipped
everything accumulated in `[Unreleased]` since v0.3.0. The details of the
changes are in `CHANGELOG.md`, section 0.4.0; the carried-over behaviour
changes are the `TagEntry` named struct, the `CommitBelongsToOtherTable`
message, the `tag list` table column, the structure gate, the Rust 1.82 →
1.98 toolchain move (ADR-0010), and the 10,000-commit traversal bound
(ADR-0011).

### Supplement: crate provenance

Beyond the `src/` diff already recorded, each published `.crate` carries
`.cargo_vcs_info.json` whose `git.sha1` pins the exact packaged commit:

- `verge-core 0.4.0`: `sha1 602bd235c1e08050d76a018efc6feab9dec07149`,
  `path_in_vcs crates/verge-core`.
- `verge-cli 0.4.0`: `sha1 602bd235c1e08050d76a018efc6feab9dec07149`,
  `path_in_vcs crates/verge-cli`.

Both equal `git rev-parse v0.4.0^{commit}`, verified from copies downloaded
from `static.crates.io`. This is VCS-level proof cargo packaged the tag
itself, independent of the directory diff — the same provenance class the
backfill audit records for 0.1.0–0.3.0.
