# Audit: rilis v0.3.0

## 2026-10-04 — Rilis v0.3.0

| Field    | Nilai                                                                |
| -------- | -------------------------------------------------------------------- |
| Waktu    | 2026-10-04                                                           |
| Aksi     | Terbitkan GitHub Release `v0.3.0` dari tag di `main`                 |
| Pelaku   | Miruameli                                                            |
| Alasan   | Menutup issue #22 dan #25; rilis tanpa binary, checksum, dan SBOM dilarang |
| Terkait  | Issue #27, PR #23, #24, #26, ADR-0007, ADR-0008, ADR-0009           |
| Dampak   | Empat binary lintas platform dapat diunduh dan diverifikasi            |
| Rollback | Tag dan rilis dapat dihapus; artefak immutable tidak menyentuh data pengguna |

### Isi rilis

Milestone 4: branch sebagai pointer O(1), merge tiga arah dengan empat strategi
resolusi, `verge query --as-of <WHEN>` untuk waktu, tag, atau commit, serta tag
immutable. Rincian perubahan ada di `CHANGELOG.md` bagian 0.3.0.

### Catatan kepatuhan

- Tag hanya pernah menunjuk commit di `main` yang sudah hijau.
- Rilis terbit hanya setelah `sha256sum --check --strict` menerima seluruh
  checksum; job publish gagal bila satu saja tidak cocok.
- SBOM dibuat dari `cargo metadata --locked --filter-platform` sehingga dapat
  direproduksi dan tercatat di lockfile.

### Artefak yang terbit

```
SHA256SUMS
verge-0.3.0-x86_64-unknown-linux-gnu.tar.gz
verge-0.3.0-aarch64-unknown-linux-gnu.tar.gz
verge-0.3.0-aarch64-apple-darwin.tar.gz
verge-0.3.0-x86_64-pc-windows-msvc.zip
verge-<target>.cdx.json   (SBOM CycloneDX 1.5 untuk keempat target)
```

### Bukti

- Workflow `release.yml` pada tag `v0.3.0` selesai dengan `success`; run
  `37139489250`.
- `sha256sum -c --strict SHA256SUMS` menerima kedelapan berkas setelah diunduh
  ulang dari GitHub Release.
- SBOM CycloneDX 1.5 memuat 13 komponen untuk target aarch64 dan 12 komponen
  untuk target x86_64, dengan `verge-core` sebagai komponen utama dan `sha2`
  tercatat sebagai dependensi tunggal.
- Binary `aarch64-unknown-linux-gnu` hasil rilis menjalankan alur nyata:
  `init → import → commit → commit → log → diff HEAD~1..HEAD → branch
  create/switch → merge --strategy ours → tag create → tag list →
  query --as-of q3 → show HEAD`. `verge --version` melaporkan `verge 0.3.0`,
  `verge diff` mencetak `+ 2 ,budi`, dan `query --as-of q3` mengembalikan isi
  yang sama seperti `show HEAD` setelah merge.
- Rilis terbit pada 2026-10-03 17:10 UTC dari commit `1d09f98` di `main` yang
  sudah hijau pada kelima quality gate.
