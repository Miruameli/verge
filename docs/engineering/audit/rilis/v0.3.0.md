### Release contents

Milestone 4: branch as an O(1) pointer, three-way merge with four resolution
strategies, `verge query --as-of <WHEN>` for a time, tag, or commit, and
immutable tags. The details of the changes are in `CHANGELOG.md`, section 0.3.0.

### Compliance notes

- A tag only ever points at a commit on `main` that is already green.
- The release is published only after `sha256sum --check --strict` accepts every
  checksum; the publish job fails if a single one does not match.
- The SBOM is generated from `cargo metadata --locked --filter-platform` so it is
  reproducible and recorded in the lockfile.

### Evidence

- The `release.yml` workflow on tag `v0.3.0` finished with `success`; run
  `37139489250`.
- `sha256sum -c --strict SHA256SUMS` accepted all eight files after
  re-downloading them from the GitHub Release.
- The CycloneDX 1.5 SBOM contains 13 components for the aarch64 target and 12
  components for the x86_64 target, with `verge-core` as the main component and
  `sha2` recorded as the single dependency.
- The `aarch64-unknown-linux-gnu` binary from the release runs a real flow:
  `init → import → commit → commit → log → diff HEAD~1..HEAD → branch
  create/switch → merge --strategy ours → tag create → tag list →
  query --as-of q3 → show HEAD`. `verge --version` reports `verge 0.3.0`,
  `verge diff` prints `+ 2 ,budi`, and `query --as-of q3` returns the same
  contents as `show HEAD` after the merge.
- The release was published on 2026-10-03 17:10 UTC from commit `1d09f98` on
  `main`, which was already green on all five quality gates.
